# Generic Objective Bend typed preview

`native/bend-source/objective-preview.ts REQUEST_JSON OWNED_EMPTY_OUTPUT_DIR PINNED_TOOLING_JSON` consumes an immutable `objective-frontend.ts` captured package. A server-owned tooling configuration pins the actual parser, source elaborator, preview host, compiler runtime and qualified type/runtime dependencies. Browser clients must supply capture identifiers through the Studio capture service; they cannot select filesystem or tooling paths.

The request schema is `dregg.objective-bend.preview-input.v2`: `capturePath`, its exact `captureSha256`, `arguments` (canonical decimal Nat strings, Booleans or recursive records), `projections` (`{field,argument?}`), and `limits` with positive canonical decimal strings `ticks`, `heap`, `stack` (each at most 100000) and `typeFuel` (at most 16384). The frontend retains the original captured request, source/module/import and AST hashes. It reparses the exact retained source with the pinned parser and emits the actual de Bruijn core. It never substitutes an example Book or result.

The lowerer emits a core packet and annotation proposal. The adapter checks their exact term equality. `Host/ObjectiveBendPreview.lean` decodes that proposal, invokes the actual proof-producing annotated checker, and only on acceptance executes `runBounded` on that same decoded term. Closed source contexts are required. Bounds affect suspension and are recorded in the result. Source annotation proposal support is narrower than the parser: candidate 1 admits zero-argument literal declarations; candidate 2 proposes explicit Nat and named-record signatures plus captured Extension<Nat> factories. Unsupported annotations produce a diagnostic rather than bypassing the checker. New source signatures can extend that producer without replacing the checker.

Success is `dregg.objective-bend.preview-result.v2`, with `status` (`finished`, `suspended`, `divergent` or runtime `refused`), `binding` (capture/source/core/typed-packet/tooling hashes and requested limits), and `preview` containing the actual type, uses, typed ground result and machine capacity observations. A source/type/tooling refusal uses the same outer schema with `status: refused` and a structured `diagnostic` stage/message; exit status is 2. Machine outcomes are JSON results and exit 0, including honest suspension/divergence. Outputs are created in an empty owned directory and never modify the capture or Studio store.

This is a clear, effect-free preview of the new Objective edition. It does not admit native current observations, affine effects, private ciphertext inputs, law discharge or world receipts. Elaboration adequacy and demand-machine preservation remain independent theorem obligations. The older BendTT checked Book path remains a separately labelled embedded fragment. Both candidates pin the actual repaired mix capture rule and finite row equality checker. Actual Studio capture has completed as Nat 8 through candidate 1. Candidate 2 receiving cohort adds byte-identical captured reusable closures and heterogeneous extension source; qualification is recorded independently.

The current source now targets runtime wire edition 2: `core.v2` and `typed-core.v2` contain explicit Boolean constructors. `preview-tooling.v2` and `typed-preview.v2` require that exact family. The source AST remains Objective edition 1. String `"true"` stays a String, Boolean `true` is a distinct Boolean result, and String conjunction is refused by the checker. Candidate 1/2 wire-v1 artifacts remain immutable; they are never silently decoded as wire-v2. Source-first candidate 3 is pending qualification with the world/type producer repair.

A public source package manifest is `tests/objective-bend-source/GenericExtension-package.json`. From the source root, run `bun native/bend-source/objective-frontend.ts tests/objective-bend-source/GenericExtension-package.json OWNED_CAPTURE_DIR`, then `bun native/bend-source/objective-preview-request.ts OWNED_CAPTURE_DIR/objective.json NEW_REQUEST_JSON '["7"]' '[]'`. The latter computes the actual capture hash, rather than requiring a guessed example digest. Invoke `objective-preview.ts` with that request, a new result directory and a server-owned pinned tooling configuration built for the same wire edition. The manifest selects the reusable captured extension source; its result for seed 7 is 12. A portable default compiled tooling installation is not provided by these examples: the service must provision matching pinned elaborator/checker/runtime artifacts first.
