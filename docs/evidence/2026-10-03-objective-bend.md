- **Authored:** implementation exists; checking or execution is still outstanding.
- **Checked source:** the stated source/type/proof command passed for exact inputs.
- **Executed component:** an actual evaluator, protocol or backend ran the named case.
- **Joined native receiving:** the selected Host/client accepted or refused the
  exact operation and its durable state/result was observed.
- **Deployed:** a particular service is running with its actual installed profile;
  neither source integration nor a sealed artifact family implies this.

## What a newer claim needs

Before moving a row from source/component to joined native receiving, retain the
exact source/module and executable pins, selected profile, input bytes or lawful
reproduction fixture, command, result and durable readback. Check a meaningful
refusal and retry where the contract calls for them. For private execution name
the ingress, arithmetic, observer, trust, custody, capacity and release assumptions.
For an activity include restart and stale-worker behavior; for a distributed
operation distinguish decision, install and delivery.

This is one checkpoint, not a standing count dashboard. Add a new dated evidence
record for a new coherent receiving result and link it here or from the guide;
do not rewrite older recorded outcomes as though they ran on later source.
