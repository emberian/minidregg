Native provisioning and the actual Hermes prompt/readback evidence are owned by the separate workroom lanes. The `render-hosted-pair` synthetic recipe test used tasks 7891/7893; it was not the source of these live 7801/7803 overlays.

The fresh signed Mini Store was handed off after native birth/delegation and unrelated-resource refusal checks.
