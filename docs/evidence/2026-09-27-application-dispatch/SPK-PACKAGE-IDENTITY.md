# Strict signed SPK descriptor source gate

Its strict canonical frame binds the full raw 32-byte SPK SHA-256, byte length, signer-derived 52-byte AppID, signed upstream app version, full SHA-256 of the signed `sandstorm-manifest` and `sandstorm-http-bridge-config` members, the exact signed bridge API path, and the ordered Mini interface/schema mapping. `.root` commits that entire preimage using a separated cSHAKE domain. The raw-SHA `Digest` helper has an exact 32-byte roundtrip proof; it is not substituted for the package root. `Descriptor.matchesManifest` compares this root and the exact ordered interfaces against the existing `ApplicationDispatchManifest.Manifest` type. The signed upstream AppVersion (GitWeb 10) is distinct from Mini's installation revision (initial 0→1); no numeric equality is asserted.

The v1 Mini adapter mapping is exact: web interface id1/v1, optionally API interface id2/v1 with the same signed ViewInfo schema and `/repo.git/` as the only accepted API path. Source checks this shape; the physical host must independently compare its decoded signed bridge config and API path. The SPK signs schema/path but does not sign Mini id/version/kind labels.
