# SPK resident lifetime v3 caller gate

This source cut wires the versioned agent listener into the existing resident MainPID and its one GitWeb `RpcDriver`. The forward operation ID and exact HTTP bytes are retained before the controller's source-owned op80 reserve. The resident re-inspects that plan, gets three detached payer signatures from controller custody, signs only its app/grant slots for op78/79, requires a fresh installed op76 permit, obtains a durable `mark-send-v3` ACK, and queues one fd3 call. It retains the exact serialized HTTP response and SHA-256, requires the controller's definite settlement ACK, and only then retains/returns `http-v3`.

On lost settlement ACK or crash after settlement, `inspect-v3` uses the original operation/binding/fingerprint and the controller's read-only `inspect-settlement-v3` (native exact settlement plus signed terminal purse proof). It compares the saved HTTP-byte SHA and op76 receipt, recovers the exact hostd tombstone/slot and per-route active marker, then saves the exact reply. It never resends fd3. An already complete historical reply is read from its exact retained files without touching a newer route marker. Controller worker wall is an exact protected configuration/request/echo join; the reverse timeout is bounded below that wall and hard EOF remains independently cancellable.

If a caller disconnects after the durable mark-send ACK but before fd3 enqueue, that route retains an uncertain purse/send marker for audit. The linear no-enqueue fence can release only the shared hostd slot; it does not cancel or replay the controller's marked attempt. Likewise, a controller settlement that remains unverified by read-only inspection stays uncertain, even if local response bytes exist.
