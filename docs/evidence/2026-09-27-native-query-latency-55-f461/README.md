# Matched retained-query read: 55d3868 versus f461f39

This is a read-only, keyless Host comparison on hbox, not a deployment or an isolated measurement of the canonical-prepare change. The old Host was the certified exact `55d3868` ELF (SHA-256 `a9e5cf96015b8439b596e602cd7685773dc5eebf96356bc0c8cc5f22b7c46f87`); the new Host was the certified exact `f461f39` ELF (SHA-256 `3bbdc8474cca00a3a080f9120acba39ee551ca47d9506573dc37115dc26df55b`). Their build manifests are retained in `../2026-09-27-native-55d3868-host/` and `../2026-09-27-native-f461f39-host/`.

The input was the retained post-reserve signed observation (583 bytes, SHA-256 `c0a35270625856ca8f62177175bab7926bdb719805500f776559d92458fb6714`) and the closed post-reserve SQLite Store (688,128 bytes, SHA-256 `4c3685f51196665e95605462e5779b46bc2fff271e2b82609e2021e6f239dbb5`). The private pinned config has SHA-256 `1157c0aa8b8047b6b1e5e3b6d76b4cd99b9c99f094248d07947e6867fe568f94`. Its configured storage and signature helpers were unchanged, with executable SHA-256 `9a5054813d9ad358ece337b99121cb37a36ba82b4b92ad0e287dcc7e529190e0` and `e80a0949d0ce16b24bcf24f2ac1306f4e194887ba11d328121b4c3345f8dfa1a`, respectively. No key was used or copied.

For each process, a separate 0700 directory held a fresh byte-identical Store copy and config that differed only in `storageRoot`. The call shape was `HOST COPIED_CONFIG query COPIED_SIGNED_OBSERVATION.bin NEW_VIEW.bin`, measured by `/usr/bin/time -v` through `timeout 600`. The four calls ran sequentially in old/new, then new/old order. All exited 0, returned the same 101-byte raw view (SHA-256 `dac7842a355077c58af33704f2fcf22bc70a20fb9a4de5ba3c3bf1c2a1f1708d`), and left each copied Store at the original SHA-256. Exact measurements and private timing-log hashes are in [timings.tsv](timings.tsv).

The new Host used 83.04 and 81.72 seconds wall time, with 76.62 and 76.61 seconds user CPU. The old Host used 104.61 and 158.02 seconds wall time, with 98.15 and 142.38 seconds user CPU. The old Host's second sample varied materially despite identical input and output. These are two cold stdio samples per source cut under ambient hbox load, so they establish output equivalence and observed timings, not a stable speedup estimate or attribution to one source change.

An initial check used the retained *pre-reserve* signed observation (SHA-256 `852ae5d0e70ad741c04991cad3b08e5dbc5a35e6c80fcd46e78c501f2c066215`) on the *post-reserve* Store. Both Hosts correctly refused it (exit 1, no view) and left their copies unchanged. Those refusal timings are included separately in `timings.tsv`; they are not successful-read measurements.

Private fixture inputs, copied Stores, raw views, and complete `/usr/bin/time` logs remain under `/tank/dregg-build/minidregg-query-latency-55-f461-private` on hbox. Only hashes and aggregate measurements are published here.
