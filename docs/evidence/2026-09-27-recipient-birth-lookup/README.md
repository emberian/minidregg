# Recipient historical call receipt (source checkpoint)

This is a recipient-only, read-only lookup for an **exact signed Mini call**. The current composite application-birth fixture (`scripts/application-current-birth/native-share-base.sh`) authors a binary intent and submits it through the ordinary Mini submit path. The client retry dispatcher maps `lookup` to native operation 3; public transport admits operation 3. The new `mini historical-call-receipt-lookup` route invokes only that operation, retaining the exact call, lookup marker, full reply frame, binary outcome, and pinned Host-rendered outcome JSON in a fresh private directory. It checks the original transaction ID, event ID, accepted count, and image boundary against the replayed native receipt. Host/config/call digests are checked again after transport and presentation.
