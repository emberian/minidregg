# Ordinary source-agreement reader

Host.SourceAgreementReader is an additive stdio consumer of the qualified native
receiver. The CLI is READER CONFIG stdio. Ops0,1,3,4,5,6,7,8,9,10,11,91,144 reuse actual
source-native describe, authorized preparation, exact lookup, signed observation,
and canonical detached assembly. Every stateful operation reopens the actual
configured Store. It contains no source mutation path: op2 and all other opcodes
refuse. The Python operator routes only op2 through the four-participant agreement
consumer, retaining the original canonical SignedCall.

Settings preserve the actual deployment/template/tariff/storage/signature/runtime
fields and the same exact Context/source-genesis anchor check as Main. The reader
requires an explicit consensus pin and refuses unknown settings, rather than
silently omitting a requested optional runtime profile. The signature executable
is privately snapshotted for process lifetime using Main's existing mechanism.
No private signing key enters this process.

SourceAgreementJson is a narrow projection of existing Host.Json (source hash and
selected definitions recorded in the lane's reader-json-extraction.json). It
preserves its duplicate-key and depth checks, selected ordinary JSON grammars and
the native canonical codecs. Unsupported author/inspect families refuse. Fresh
document/content/world-kind/birth setup and ordinary review are the intended
consumer; this is not a replacement for the broad application operator.
Opcode91 retains the existing sponsor-signed current factory-observation gate,
uses the actual native opened authority and height, and returns an intent only.
Opcode144 retains the current key-status lookup; no key-check bypass is supplied.
The document/context/resource-scope renderers consume the same current native
resource-view codecs. Read-only legacy metadata codecs/inspection are extracted
from LegacyContentCarry, with exact original tags/bytes/roundtrip lemmas and no
migration functions. This keeps complete legacy-reference/mark presentation.
A restricted simp proof avoids unfolding a closed cSHAKE digest in the extracted
document roundtrip theorem; it proves the same statement. The complete original
migration module has a further compile-time bottleneck and is not needed here.
The next shared refactor should place ordinary grammar in a reusable
module consumed by both Main and this reader, instead of growing two copies.
