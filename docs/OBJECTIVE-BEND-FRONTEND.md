# Objective Bend source capture, edition 1

`native/bend-source/objective-frontend.ts` reads `dregg.objective-bend.package-input.v1` with edition `objective-bend-1`, modules `{name,sourcePath,imports:[{alias,path,module,sha256?}],sha256?}`, canonical decimal-string module indices, and entryModule/entryDefinition. Imports reference earlier explicitly listed modules using `./NAME.obend`; the manifest locks both alias and path. Each source is read once, strict UTF-8 parsed, and snapshotted with immutable creation. Optional expected hashes refuse changed bytes. No source import fetches a filesystem path or network location.

The output `objective.json` records actual module/source/import hashes, source byte spans and independent AST files. `package-input.json` feeds the existing canonical Mini Package producer; its cSHAKE identities remain distinct from the recorded SHA byte fingerprints. This is a source and AST producer. World owns the independent Objective reference elaborator, demand machine and typed/effect admission. The parser does not claim the inherited BendTT theorem for this new edition.

The accepted syntax includes records with fields and method signatures, specs with actual method bodies, requirements and laws, separately typed extensions, anonymous captured extension values and functions, record construction/extension, member calls, composition, lazy fix, zero/successor matches, and arithmetic/Boolean expressions. Ordinary types remain annotations for the semantic elaborator. `self` and `super` remain genuine lexical source references. The parser neither rewrites them into affine callback placeholders nor forces mutually recursive method calls through embedded BendTT totality.

The six source probes distinguish repeated final-self calls, descending even/odd mutual methods, heterogeneous inherited/context/output extensions, captured reusable extensions, whole-function super and unforced incomplete specification values. The imported ReviewBase/ReviewMember pair exercises the same features across a locked source package. Parsing these programs is not evidence that they execute correctly; consume the actual AST through the new Objective core to establish that behavior.

Embedded pure Bend uses the separate pinned `member-frontend.ts` parser/emitter and Mini Book admission. Native plan binding and effect authority are further consumers. Neither parser returns an execution receipt or mints current authority.

Ordinary return-form functions may omit parameter/result annotations; the AST records `_` for inference rather than silently choosing a type. Named imports `import Alias from "./NAME.bend"` are sealed exactly like `./NAME.obend`. The explicit CLI option `--objective-edition-1` adopts an existing `dregg.bend.package-input.v1` signed capture as source for this edition without mutating request or module bytes. The output records the original request SHA, request schema and `editionSelection=explicit-caller-adoption`; it is not automatic semantic admission or inherited BendTT typing. The ordinary Studio capture therefore stays identifiable while the new language owns its return-form inference and operational meaning.
