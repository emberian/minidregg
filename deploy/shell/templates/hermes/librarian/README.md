# hermes/librarian

Read by `summon ROOM as librarian` (compiled into `mini`): `budget.json`
(`fund`, the default budget), `grants.json` (the room grant, `ROOM-index` and
`ROOM-digest` with their law, the program document's name and law),
`program.md` (written into the room as `ROOM-hermes-librarian`). The steps are
in `../README.md`.
