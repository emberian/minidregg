Persvati, 2026-09-26. This is a **private fixture demo** using the already-provisioned Mini parent grain 7001. It uses the account owner's existing `ssh persvati` login; no public listener, friend `authorized_keys` entry, new account, fn service, paid provider, or BYO provider key was installed. The Mini host and controller were active at the final check. They may no longer be active when this note is read; check the units before connecting.

From the owner's laptop, run:

```sh
ssh -T persvati '/tmp/mini-grain-ssh-live.i35dUm/deploy/grain-host/grain-ssh /home/ember/mini-grain-owner-demo-20260926/bin/grain-runtime /tmp/mini-grain-ssh-live.i35dUm/evidence-native/runtime-state/control.sock soft'
```

Wait for `attached soft to Mini grain 7001` (signed policy renewal took several minutes in this run), then type `status`, `run short`, and `disconnect`, one line at a time. `short` is a five-second, systemd/bubblewrap-scoped sleep fixture charged one Mini allowance unit. A soft SSH disconnect lets an already-running bounded operation finish. Do **not** run `hold` or `hermes` in this demo: `hold` is a long test worker, while the old Hermes command is journal-bound to a stopped deterministic provider fixture and an older mounted MCP proxy. This task has no signed `providerTask` gateway and supplies no BYO provider credentials. A real Hermes prompt requires the separate current gateway/profile validation and a fresh qualified setup.
