What Mini Is
People, Sandstorm grains, and autonomous agents all share one state tree and submit signed proposals through the same admission gate.
The admission kernel is written in Lean. Every transition is checked against current capability grants and the target resource's installed law before any state changes.
Each admitted turn advances the world root and produces a signed receipt binding the new state digest.
Rejected turns leave state untouched and return a structured refusal naming the exact clause that failed.
Dropped network replies leave an attempt undecided in local custody so retrying resends the exact sealed call bytes once.
Computation proposes; authority admits.
