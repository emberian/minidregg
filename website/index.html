formal-first · derived path only

A proof-native semantic computer.

minidregg is a Lean-owned kernel for authorized state change: typed requests, multi-cell hyperedges, heterogeneous proofs, and causal documents that agents and humans can actually inspect.

How it’s built What’s closed (honestly) Source on GitHub

One sentence

Lean owns meaning. Native code returns bytes or fails.

Users and agents authorize, execute, inspect, link, merge, and compress heterogeneous state transitions — without giving native code, runtime objects, or storage handlers a second source of meaning.

Four pillars

Built as one construction, not four side projects. Each pillar advances through explicit maturity boundaries (S → A → P → D → B).

01

Semantic kernel

Typed requests, request-indexed authority, canonical transitions, flat multi-cell hyperedges, and receipts.

02

Loom

Heterogeneous proof fabric: binary fields, prime fields, lookup/RAM, FHE rings, privacy, and history meet at checked joints.

03

Hyperdocuments

Proof-native causal medium: typed content, transclusion, backlinks, offline branches, explicit conflicts, versioned history.

04

Compiler boundary

Lean-owned artifacts describe native work. Opaque native code returns bytes or an error. Only Lean accepts a turn.

What you should be able to ask

As a user

  • What exactly changed, root → root?
  • Which request, authority, and private work justified it?
  • Which causal parents made this document current?
  • Is a conflict explicit, or was a writer silently lost?
  • Can I hand a compact proof of this history to another device?

As an agent

  • Follow typed content-addressed links and backlinks
  • Inspect only authenticated coordinates of large objects
  • Publish several effects as one balanced hyperedge
  • Branch offline and merge without erasing provenance
  • Invoke sealed computation without disclosure authority

Founding move

The derived path is the only path.

minidregg reimplements the lessons of a multi-million-line formal stack at a fraction of the size. The diagnosis: every lowering was sound, but almost none of them replaced the hand-written twins they should have deleted. Here, nothing lands beside what it supersedes.

Statement-first. Keystones enter as propositions with satisfiability, teeth, and premise-inhabitation before proof work. A wrong statement proved fast is the expensive failure.

Honesty policy

Maturity labels, not vibes

Every substantial claim is labeled by the strongest boundary actually closed: S A P D B

“Complete” without one of these is avoided. See current status.

Frontier research, not a product

This is a frontier research stack. Several carriers are exhibited at built parameters; some deployed schemas are still uninhabitable. Nothing proved is false — and vacuity is called out by name.

North star

Fit to carry tools like helm.

The fleet-coordination layer — rooms as cells, posts as signed turns, premises as attested claims, review verdicts and land-receipts as receipts on chain — is a first-class target application. Our own development fleet is the first user.
