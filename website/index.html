Mini

Mini is a programmable shared world for people and agents. Documents, applications, communities and continuing computations share one set of rules for authority, resources, privacy and history.

Underneath, Mini is a small store of owned resources. Every action is a signed request that the Host, a program written in Lean, admits or refuses. An admitted request leaves a receipt. A refused one comes back with a reason.

State, in one paragraph. Mini is a devnet. When the data model or the kernel wire changes, the store is re-genesised and everything made on it is gone. Nothing has an uptime promise. The public node runs a candidate from 2026-10-01 with the shell, documents and boards. It has no rooms, chat, key rotation or proxy mode, and no outside member is enrolled. No admission uses a proof: admission is checked by re-execution. Private rooms are devnet quality and their privacy is not audited. None of the private execution research runs a member's program privately today. Full status.

How it is built

  • Lean owns semantics and admission. Every change is a proposal that the Lean kernel admits or refuses against current capabilities, laws, exact read roots and funding. The kernel checks a computation by running it again, at admission and again on every replay.
  • Rust owns the physical boundary. The Rust side supplies clients, signing and custody, storage, transport and hosted-service adapters. It decides nothing semantic.
  • Resources carry laws. A law is a predicate the Host checks on every change to a resource. A law that forbids everything locks the resource: neither its owner nor the operator can get past it.
  • Computation proposes; authority admits. A correct calculation cannot grant itself permission, a reference is not ownership, and a lost reply keeps the original operation and its exact retry rather than licensing a second one.
  • Objective Bend is the language. It is a lazy language of first-class, partial, composable specifications, after Faré's account of objects. Its core has machine-checked soundness, preservation and completeness theorems, which the default build does not yet re-check. No Objective Bend program has yet been admitted by a native Host.

Who it is for

The design aim is a world where members inspect how their tools work, compose new behaviour, delegate bounded work to agents, and change their shared world without handing any application unrestricted access to the rest of it.

Today that means two groups. Friends can use a hosted shell on the public node, with the limits on the join page. Contributors can read and build the repository: useful work improves a tool or world, closes a source-to-runtime connection, deletes a duplicated mechanism, strengthens a proof, or exposes a claim the evidence does not support.
