Evidence discipline

Maturity boundaries

Every substantial claim is labeled by the strongest boundary actually closed. An S theorem is not D. An A controller is not P. Quote the pessimistic number.

Legend

Level Meaning Does not imply
S semantic Lean carrier, relation, theorem, reduction shape, or exact codec exists. Executable online control or cryptographic security.
A admission Lean-owned controller consumes bounded bytes/errors and can construct the sole accepted result. Cryptographic premises reduced and priced.
P proof Concrete PCS / commitment / ROM / proximity / ZK assumptions and reductions joined on the relevant game coin and error budget. Deployment, persistence, or consumer cutover.
D deployment Authenticated artifacts, codecs, controllers, handlers, and storage joined and used by a real consumer. Competitive performance.
B benchmark Reproducible committed-source evidence measures the selected path against a stated workload. Semantics, security, or a universal performance threshold.

Current construction (snapshot)

Condensed from the repository README. For the full residual text, read README.md and the evidence ledger in GOAL.md.

S A

Canonical semantic turn

AcceptedCellEffect retains one exact authorization token, effects digest, and pre-root. Request binding adds family-selected lawful argument projection. DeclaredHyperedge composes a flat, balanced multi-cell turn.

Residual: digest reflection/CR explicit; physical CAS, WAL recovery, replication, and consumer migration still need deployment refinements.

S

Durable settlement

Model names root CAS, nullifiers, exact multi-cell charge, history append, idempotency, and crash outcomes. Kernel.DurableWalHandler inhabits the refinement as a staged/committed/compacting WAL model.

Residual: device model only — no fsync, torn record, page cache, or liveness claimed.

S A

Hyperdocuments

Typed content, links/transclusions, marks, causal events, publication, merge with provenance-bearing conflicts, versioned first-order interface negotiation.

Vacuity caveat: at some deployed schemas, LogicalState is a total function over an infinite address space, so no materializer can inject it into List UInt8. Theorems quantified over those cells are true and currently worthless until state is finitely supported.

S A

Reactive / private computation

Reactive promises fix late-advice codecs, wake from verified history, retain observed pre-root and replay nullifier. Private computation remains sealed. Note-spend path has a bytes/error controller with roots-before-challenge control.

Residual: proof-suite ID still 0; PCS/CR/ROM/PoK/hiding are premise-shaped, not implementations.

S A P*

Tower256 additive FRI

Exact Tower/Fan–Paar coordinates, cSHAKE framing, Merkle schedule, coherent openings and folds. Accepted bytes select the literal challenge/query coin; false acceptance derives into additive-proximity or oracle-transport failure.

Residual (*): conditional P — exact cSHAKE/common-coin transport remains a premise; collision bridges exist without priced probability; matched E2E benchmark remains.

S A

Tower256 lookup / LogUp

Canonical Boolean addresses, exact unit-vector incidence. Extension-only clause-404 controller fixes shared backend and accepts exactly two keyed native byte replies.

Residual: clause 404 still gated out of base V1 deployment; position binding and sampled-decider soundness open.

S A D B

Compiler & native authority (narrow path)

Clause 406: authenticated artifact / native work / controller / deployment join. Honest generated bytes certify; malformed bytes reject; native errors block. Dispatch microbenchmarks exist.

Residual: base V1 still has zero clauses; 406 is the BabyBear add-1 zero-witness descriptor path — not a deployed full proof system, and never a Rust correctness theorem.

What runs today

No authoritative one-call Rust prover API

Deliberately. Former parallel prover/verifier paths that duplicated transcript and acceptance semantics were deleted. Current native source is limited to fallible arithmetic, transform, hash, and MLE/lookup candidate compute plus generated artifact/dispatch data.

Five concrete controller seams exist: arithmetic clause 406, Tower256 additive FRI, extension-only lookup 404, Ext6 gate proof, and sealed note spend — each with its residual security or deployment obligations stated in-repo.

Carriers

A theorem over an empty type is true and worthless. Load-bearing carriers are exhibited at built parameters with refutations showing their equations are constraints. Deployed-schema inhabitation is a separate, tracked obligation.

Consumers (subsumption, not elegance)

minidregg is not a replacement kernel because its model is pretty. Each consumer family needs a real adapter and cutover:

Consumer Required for replacement
Drex / FHEgg / Dark Bazaar private compute, ring proof, resource effects, settlement, separately authorized release
DeOS / agent platform reactive projections, promises, tools, intent/completion receipts
token authorization typed request, current authority/revocation/nullifier, canonical accepted effect
Grains causal receipt chain and succinct checkpoint with retained semantics
DreggNet control plane multi-resource command, durable settlement handler, external completion evidence
