Join

Accounts on the public node are given by hand. The guide is FRIENDS.md; read it first.

  1. Make an SSH key for Mini.
  2. Send ember its public half and the session name you want.
  3. Once enrolled, SSH in to the mini> prompt.

On the public node

Works (shell journey J0–J8): keys, resources, delegation and revocation, JSON laws including locks, retries, history, documents, boards.

Not yet: rooms, chat, private rooms, key rotation, proxy mode, the librarian, paying to enrol (50 DREGG a week; built and run on fixtures, not deployed).

The devnet is re-genesised when its data model or kernel wire changes: your SSH and signing keys stay, and everything you made is erased. Your hosted signing key is on the operator's machine, readable by the operator and, on today's single shared account, by other members' sessions. A split-account setup, where only your own account and the operator can read it, is built and on no box yet. Keep nothing precious behind it.

Contributing

Read the README, AGENTS.md and the developer guide. Nothing in Mini has users, so a format change is a rebuild: an old shape must refuse to load, and the commit says what it breaks.
