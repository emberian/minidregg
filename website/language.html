Objective Bend

Mini's language: lazy open recursion over first-class, partial, composable specifications, after Faré's account of objects.

Mini supplies what the language does not: identity, authority, effect admission, funding and disclosure.

Core4

  • Specification: a value of type C → V → W. Given the final self and the inherited super, it produces a new value.
  • Composition: mix(lower, upper) = λself. λsuper. upper self (lower self super); fix(spec, inherited) computes the fixpoint.
  • Laziness: call-by-name reference semantics, call-by-need machine. {good = 7, bad = self.bad}.good is 7.
  • Activities: perform yields a typed Plan; the program resumes on a typed Response.
  • Types: the checker returns a typing derivation. Affine and linear quantities are checked as at most once.

Example

spec Base for Shop:
  def price(n: Nat) -> Nat:
    n * 3n

spec Billing for Shop:
  def bill(n: Nat) -> Nat:
    self.price(n) + 1n

spec Surcharge for Shop:
  def price(n: Nat) -> Nat:
    super.price(n) + 2n

Billing calls self.price, so it sees a layer added later. bill(2) is 7 under Base and Billing, and 9 once Surcharge is composed in. A gate re-runs every command in the tutorial and fails on any changed output.

Proved

In Theory/ObjectiveBend*.lean; axioms propext, Classical.choice, Quot.sound; no sorry.

PropertyStatement
SoundnessIf the bounded machine finishes a closed term, the reference semantics evaluates it to the machine's result (weak head).
PreservationEvery machine step preserves typing.
No refusalA closed term the checker accepts never reaches a refusal. It may still diverge or exhaust its limits.
CompletenessA closed term that evaluates to an observable value finishes on the machine in finitely many steps, given large enough limits. No bound on those limits is proved.
Fast machineEvery compiled call runs a fast machine proved equal to the specified one.

Not proved, not wired

  • The default build re-checks none of these proofs.
  • No theorem relates .obend source to Core4; the TypeScript front end is trusted.
  • No native Host has admitted an Objective Bend program, and no kernel delivers a response to an activity.
