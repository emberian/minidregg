ATLAS §6

Sixteen design laws

Each law was purchased with a documented wound. They are process constraints, not slogans — the size target is also a process target.

01

Naming is faking.

A class or def : Prop hypothesis is an assumption the axiom pin cannot see. Carriers are typed obligations with a realizer-or-FLOOR slot; the unrealized census is a query, never a hand-count; every carrier must be refuted at a broken sibling oracle.

02

A keystone that can’t exhibit both poles doesn’t compile.

Kernel-clean + true + vacuous happened repeatedly. Declaration-level satisfiable + teeth + premise-inhabitation, CI-gated beside the axiom pin.

03

Model the deployed field from line one.

ℤ-for-BabyBear hid real soundness gaps. The field is a parameter instantiated once at the deployed value; toys are type-distinct from the soundness path.

04

Bound ≠ forced, as types.

“Commitment binds X” is scaffolding; “the gate forces X” is where soundness lives. Two types, no coercion; apexes only over the second.

05

One executable tower.

Abstract towers quantifying over their own vocabulary are parallel proofs no live code runs. Abstraction = generalization of the live types; instance in the CI closure or it doesn’t exist.

06

Wire-first.

Orphaned built-and-tested capabilities; fee-DoS because verify was never called. Land the capability and its wire in the same commit. CI reachability gate.

07

The claims ledger is generated and unparkable.

Namespace pins beat curated lists. Parked pins were a tooling race leaking into the credibility artifact.

08

Gate the gates.

Every gate red-proofs itself, distinguishes ran-from-passed, and its ledger self-verifies without git history. Loud escape hatches, never silent ones.

09

#guard is silent native_decide.

Case-tests in Lean are still case-tests. Prove the general fact; use guards as non-vacuity witnesses, graded and confessed.

10

Refusal must be loud.

A leg the compiler can’t lower becomes an unsatisfiable boundary pair, never silence — dropping is fail-open and no byte-golden sees it.

11

Widen the source, not the emitter.

The compiler was fine; the source language couldn’t say lookups/tables/ranges. One added word moved reach. A propBit is a claim; the borrow chain is a proof.

12

Bind the policy term, not the decision bit.

Proving “the executor said admit” is not proving “the policy held.” That seam is where derived proofs stop being about the app.

13

Emit, never imitate.

Hand-written twin corpora go internally inconsistent; byte-agreement with them is ill-posed. One canonical normal form, true by construction. Delete the twin — the only move that changes the authorship count.

14

Quote the pessimistic number of a pair.

State covered scope in the same sentence as the claim. Proven parameters only — zero conjectures on the label.

15

Cost estimate → constraint is the substitution to watch.

Invented constituencies defer real fixes. If you ship a containment while naming the real fix as a later phase, the phases are backwards.

16

One lane can hold it.

Too many concurrent lanes in one tree produced parked pins, baseline laundering, and committed merge conflicts. Minidregg’s size target is also a process target.
