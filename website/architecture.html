The narrow waist

One verified semantic event

  • native statement
  • canonical representation / opening relation
  • one exact typed receipt clause
  • one shared transcript and failure ledger (when security is claimed)

Hard invariant

Lean owns state meaning, request meaning, protocol control, and acceptance. Rust has no semantics or refinement theorem in this repository. Native work returns bytes or an opaque error; failure may block availability, never authorize.

Pillar detail

SEMANTIC KERNEL

Turn = attenuable token over owned state → receipt

One typed request names subject, target, verb, arguments, effects, policy, nonce, and exact pre-root. A validated patch derives one canonical post-state and exact footprint. Multi-resource actions are flat finite hyperedges with one shared apex and aggregate law — not a hidden call forest.

Rejection has no post-state unless explicitly modeled as a charged committed effect.

LOOM

Heterogeneous dialects, owned joints

Binary towers, prime-field gates, LogUp/lookup, additive FRI, history BCS, private/sealed computation — each keeps honest native work. Shared control: roots before challenges, common-coin transport obligations, explicit failure classes on one ledger, Lean-owned admission of accepted bytes.

HYPERDOCUMENTS

Causal medium for users and agents

Typed content, stable ranges, transclusion, backlinks, annotations, offline branches, explicit conflicts, versioned history. Merge preserves every current parent: singleton field sources write; multi-source fields become provenance-bearing conflict records. Ancestry-backed accepted merge retains the selected base; ambiguous bases stay absent.

Current caveat: some document cells are still uninhabitable at deployed schemas (infinite total-function logical state). See maturity.

COMPILER & NATIVE BOUNDARY

Artifacts describe work; Lean alone accepts

Generated artifacts contain first-order data and dispatch identity, not verdicts. The clause-406 path authenticates arithmetic work with exact byte codecs: Rust returns candidate bytes; Lean decodes and constructs the certificate. Native failure can block availability. It cannot create an accepted receipt.

Privacy & external effects

Computation ≠ disclosure

Private computation is sealed by default. A later release needs new authority and a causal link to an output commitment.

Intent is not completion

An admission receipt is not proof that external I/O happened. Completion or refusal is a later event.

Analogy, not lineage

Compound documents, after removing ambient authority

Older compound-document systems had useful instincts: active documents, links, remote activation, interface negotiation. minidregg studies those ideas after removing ambient pointers, hidden mutation, location authority, and runtime object identity.
