KN2-STORE-OPEN stage (3): port lanes over the history-read leftovers
=====================================================================
Contract: Compiler/DurableHistoryReader.lean (pinned; read its header first).
Store-backed implementation: Compiler/DurableHistoryStore.lean (readerOf, atHeight, byTx,
spent, range, stateAt). Views/families: Kernel/DurableView.lean.
Generated by scripts/ports/kn2_rules.py (census + rule R1) and scripts/ports/kn2_partition.py;
every leftover file is listed exactly once below, in exactly one lane.

WHAT A PORT IS (all lanes)
- A read of an older record goes through the Reader built by DurableHistoryStore.readerOf
  (one per request/session, from the opened Loaded): atHeight / byTx / spent / range / stateAt.
- A pure receiver that reads `snapshot.model.journal` / `lookupRecorded` / `model.consumed`
  stays pure: it becomes a `DurableView.Family` (keys = every transaction id and nullifier it
  consults, INCLUDING prior transactions such as openCell.transactionId; `covers` proved), and its
  IO dispatcher runs it on `DurableView.view served (← reader.footprint keys).toFootprint`.
- A per-request genesis replay of a prefix (NativeHistorySelection, *History.select, atPrefix,
  loadImage of a cut) becomes `reader.stateAt h` (latest retained checkpoint + <= 63 records).
- A full scan on a request path becomes an index read or a BOUNDED `reader.range`; an unbounded
  scan left on a request path is a defect the review rejects.
- Never map a `Refusal` to "absent"/`none`; surface `refusal.message` (it names the height).
- `x.image.accepted.length` is `x.height` (rule R1 already applied where mechanical).
- No sorry, no axiom, no weakened theorem statement; a theorem whose statement mentioned
  `loaded.image` is restated over the Reader's answers or keeps `loaded.image` (stage 2a still
  holds it) — say which in the commit.

BASE COMMIT for every lane: the rule-pass commit named in the deputy's brief (lane/kn2-store-open
on burst2-b). Lanes branch from it; they never rebase onto each other (files are disjoint).

ACCEPTANCE (every lane)
1. Build: `lake build Minidregg Host.Main` once at the end in a held slot (burst2-b slots 1-4),
   plus `Compiler.DurableStoreAudit`; log path in the report.
2. Executed: scripts/kn2/history-tamper.lean still PASSes (logs), and the lane's own tamper
   extension (below) PASSes.
3. Planted fault per group (must turn RED, log both): a one-byte tamper of a NON-head record
   that the group's ported path reads; the path must refuse naming that height through
   DurableHistory.Refusal.message, not answer "absent" or the stale value.
4. `grep -n '\.image\.accepted' <your files>` shows no computational use left (theorems may
   keep it in stage 2a; list them).
5. Journeys: the rows that exercise the group (named per lane below) on a fresh world built from
   the lane's binaries, if the journey runner is available; otherwise say NOT RUN.

REVIEW PROTOCOL (KN2 reviews every batch before it is queued)
- Read the diff: every replaced read goes through Reader/footprint; no Refusal -> none; no new
  unbounded scan on a request path; families declare every lookupRecorded key (grep the
  receiver for lookupRecorded/model.consumed and compare with `keys`).
- Statement check: diff of every changed theorem STATEMENT; no premise added that is not
  inhabited by a named instance; no weakened conclusion.
- Evidence: the closure build log (rc 0), the tamper probe log, the planted-fault RED log.
- OB-ENG-owned files: hunks go to DEPUTY-OB-ENG (a667f3ddb2cf279db) for review before queue;
  port on top of whatever OB-ENG ranges have landed (object-pin, ob8-retention, seat-retention,
  upgrade-turns).

PER-LANE ACCEPTANCE SPECIFICS (in addition to the common acceptance above)
PORT-A  receivers + lookups + journal + consumed.
        Planted fault: one-byte tamper of the record of a PRIOR transaction that a receiver looks
        up (e.g. an application lifecycle's open-cell transaction) -> the receiver's dispatcher
        refuses with "durable history record refused at height H ..." for that H.
        Families: every receiver touched becomes a DurableView.Family whose keys include every
        lookupRecorded key; `covers` proved (executeFamily is the worked example).
        Journeys (if the runner is available): application lifecycle/dispatch rows, JPAY rows.
PORT-B  past states -> Reader.stateAt.
        Planted fault: tamper a record strictly below the requested height h (above the retained
        checkpoint) -> stateAt refuses naming that height; tamper the checkpoint bytes -> refused
        (openSealed). Journeys: document history / `doc show --at` rows, lifecycle history rows.
PORT-C  the walk / consent family (NativeHostReplay keeps its 50 `.image.accepted.length` sites:
        R1 was not applied there because its defs carry proof terms; port by hand).
        Planted fault: tamper a record after a client's consent anchor -> the anchored resume
        refuses by name; the operator audit path reads through Reader.range in windows.
        Journeys: J0-J8 consent rows; a `store audit` row once DEPUTY-PLATFORM's CLI lands.
PORT-D  the Host serve path and tools.
        Planted fault: tamper the record op 102 (receipt by transaction) reads -> the Host answers
        the named refusal, not "unknown transaction". Fleet head/incoming full scans go to an
        index or a bounded range. Journeys: receipt lookup rows, fleet rows.
